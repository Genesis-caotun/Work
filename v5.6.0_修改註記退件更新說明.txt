創世基金會草屯院｜工作申請與結案管理平台
v5.6.0 修改註記退件更新

【本版新增】
1. 副組長、院長、督導在案件輪到自己審核時，可使用「修改註記並退件」。
2. 管理員也可代為執行目前審核關卡的修改退件。
3. 系統會直接開啟目前待審的 PDF：
   - 輸入修改文字。
   - 點 PDF 中想修改的位置放置註記。
   - 可跨頁加入多則註記。
   - 可拖曳註記調整位置。
   - 可按註記右上角 × 刪除。
4. 送出後另存一份「退件註記版 PDF」，案件退回原申請人。
5. 原申請人下載退件註記版、完成修改並重新上傳後，審核流程會依原本規則從第一位主管重新開始。
6. 退件前已產生的核定檔會保留在案件 Drive 資料夾，檔名前加上「退件前舊版_」；本輪核定欄位會清空，避免舊章被誤認為新一輪核定。
7. 新增「退件紀錄」工作表，保存退件人、階段、時間、摘要與註記版網址。
8. 系統會寄信通知原申請人文件已被退回。

【權限規則】
1. 只有目前輪到的副組長、院長或督導可以退件。
2. 管理員可操作目前審核關卡。
3. 尚未輪到的下一級主管不能提前退件。
4. 退件後只有原申請人或管理員可以重新送出。

【使用限制】
1. 指定位置文字註記只支援 PDF。
2. Word、Excel 或其他格式仍可照原流程審核，但若要修改註記並退件，請先轉成 PDF。
3. 加入註記後的 PDF 仍須在 20MB 以內。

更新順序（請先更新後台，再更新 GitHub）
==================================================

第一步：更新 Apps Script 後台
1. 開啟 Apps Script 專案。
2. 開啟「程式碼.gs／Code.gs」。
3. 將原本內容全部刪除。
4. 複製本更新包的「Code_Workflow_v5_6_0.txt」全部內容並貼上。
5. 儲存。

第二步：只執行一次 setupSystem()
1. Apps Script 編輯器上方的函式選單選擇「setupSystem」。
2. 按「執行」。
3. 若 Google 要求授權，選 hty0814ex@gmail.com 並允許。
4. 等到執行紀錄顯示「執行完畢」。

這一步會為既有「案件」工作表新增退件欄位，並建立「退件紀錄」工作表；不會刪除既有案件。

第三步：更新既有部署
1. Apps Script 右上角「部署」→「管理部署作業」。
2. 找到目前的網頁應用程式，按鉛筆圖示。
3. 版本選「新版本」。
4. 執行身分保持「我（hty0814ex@gmail.com）」。
5. 誰可以存取保持「所有人」。
6. 按「部署」。

請更新原部署，不要另建一個全新的部署；原本 /exec 網址不需要更換。

第四步：更新 GitHub 前台
1. 到 GitHub 的 Genesis-caotun／Work。
2. 上傳本更新包內的「index.html」，取代原本的 index.html。
3. Commit changes。
4. 等待約 1 至 3 分鐘。
5. 開啟：
   https://genesis-caotun.github.io/Work/?v=560
6. 頁首應顯示 v5.6.0。

建議測試
==================================================

1. 用社資帳號建立案件並上傳 PDF。
2. 用副組長帳號登入，找到「申請待副組長審核」的案件。
3. 按「修改註記並退件」。
4. 輸入一段修改文字，點 PDF 放置註記，再按「儲存註記並退回第一關」。
5. 用原社資帳號登入：
   - 案件狀態應顯示「申請已退回修改」。
   - 應可下載「申請｜最新退件註記版」。
   - 應出現「修改後重新送出申請書」。
6. 社資重新上傳後，案件應回到「申請待副組長審核」。
7. 再測試院長與督導關卡，確認各關都只能在輪到自己時修改退件。
